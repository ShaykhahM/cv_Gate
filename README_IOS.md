# دليل تشغيل مشروع CVGate على محاكي iOS (iPhone Simulator) 📱

تم تجهيز هذا الفرع (`cvgate-ios`) بكافة الإعدادات والتصحيحات اللازمة ليعمل التطبيق بسلاسة على محاكي الآيفون في بيئة macOS وأحدث نسخ Xcode (15 و 16+).

---

## 🛠️ أهم الإصلاحات المطبقة في هذا الفرع:
1. **تحديث CocoaPods وتوافقه مع Firebase**: ضبط الحد الأدنى للنظام في `Podfile` ليكون `platform :ios, '15.0'`.
2. **معالجة خطأ Xcode 15/16 (`DT_TOOLCHAIN_DIR`)**: إضافة معالج تلقائي في `Podfile` يستبدل المتغير القديم بـ `TOOLCHAIN_DIR` لتجنب خطأ `LIBRARY_SEARCH_PATHS`.
3. **تكوينات التشغيل السريع**: إضافة ملفات الإطلاق المباشرة لـ Visual Studio Code.

---

## 🚀 طرق التشغيل خطوة بخطوة:

### الطريقة الأولى: من داخل Visual Studio Code (الأسهل والموصى بها) 🟢

1. افتح مجلد المشروع في VS Code.
2. **اختيار المحاكي:**
   - انظر إلى **الشريط السفلي (Status Bar)** في أسفل نافذة VS Code.
   - اضغط على اسم الجهاز المختار حالياً، وستظهر لك قائمة بالأجهزة المتاحة في الأعلى.
   - اختر منها: **`iPhone 17`** (أو **Start iOS Simulator** لفتح المحاكي).
3. **بدء التشغيل:**
   - من القائمة الجانبية، اضغط على تبويب **Run & Debug** (أيقونة المثلث مع حشرة 🐞 أو اختصار `Cmd + Shift + D`).
   - من القائمة المنسدلة في الأعلى، اختر:
     ```text
     CVGate (iOS Simulator)
     ```
   - اضغط على زر التشغيل الأخضر **▶** أو اضغط مفتاح **`F5`** في لوحة المفاتيح.
4. سيتم بناء التطبيق وفتحه تلقائياً داخل شاشة محاكي الآيفون.

---

### الطريقة الثانية: من سطر الأوامر (Terminal) 💻

1. افتح الـ **Terminal** وانتقل لمجلد المشروع:
   ```bash
   cd /Users/shikha/cvgate/cv_Gate/cv_Gate
   ```
2. شغّل محاكي الآيفون:
   ```bash
   open -a Simulator
   ```
3. ابدأ تشغيل التطبيق بالأمر:
   ```bash
   flutter run -d ios
   ```
   *(أو بتحديد المحاكي بالاسم: `flutter run -d "iPhone 17"`)*

---

### الطريقة الثالثة: عبر بيئة Xcode الرسمية 🛠️

1. افتح مساحة العمل في Xcode:
   ```bash
   open /Users/shikha/cvgate/cv_Gate/cv_Gate/ios/Runner.xcworkspace
   ```
   *(تنبيه: يجب دائماً فتح ملف `.xcworkspace` وليس `.xcodeproj` لربط مكتبات Firebase والـ Pods بشكل سليم).*
2. من شريط الأدوات العلوي بجانب زر التشغيل، اختر محاكي الآيفون المستهدف (مثلاً: `iPhone 17`).
3. اضغط على زر **Play (▶)** أو اختصار `Cmd + R` لبدء البناء والتشغيل.

---

## ⚡ أوامر مفيدة أثناء عمل التطبيق في التيرمينال:
- **`r`**: لتطبيق أي تعديل في الكود فوراً على شاشة المحاكي دون إعادة تشغيل (**Hot Reload** 🔥).
- **`R`**: لإعادة تشغيل دورة التطبيق كاملة من البداية (**Hot Restart**).
- **`q`**: لإيقاف التطبيق وإغلاق جلسة العمل.

---

## ❓ استكشاف الأخطاء الشائعة وحلولها:

- **إذا ظهر خطأ CocoaPods غير محدث**:
  ```bash
  cd ios && pod install
  ```
- **إذا احتجت لتنظيف وإعادة بناء الكاش**:
  ```bash
  flutter clean
  flutter pub get
  cd ios && pod install
  ```
